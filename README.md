# Escape the Horde

Escape the Horde est un jeu-vidéo de type Top Down Shooter dans lequel il faudra survivre à des hordes de zombie sur plusieurs étages.

## Lancer le projet

À la racine du projet :

- Dupliquer le .env.cp que vous renommez .env
- Lancer le projet avec la commande :

```
docker compose up -d --build
```
